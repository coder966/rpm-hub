# RPM HUB
Many apps don't ship RPMs, or at least not in a yum repo so that it can be kept updated using package managers like dnf.
This is a collection of community-maintained unofficial RPMs built from official sources.

# Apps

## Postman

```sh
sudo dnf copr enable coder966/postman
sudo dnf install postman
```

## JetBrains Toolbox

```sh
sudo dnf copr enable coder966/jetbrains-toolbox
sudo dnf install jetbrains-toolbox
```

## IntelliJ IDEA Ultimate

We recommend using [JetBrains Toolbox](#jetbrains-toolbox), mentioned above, to install and manage IntelliJ IDEA Ultimate.

```sh
sudo dnf copr enable coder966/intellij-idea-ultimate
sudo dnf install intellij-idea-ultimate
```

## SoapUI
Please make sure you have Java version 17 or higher.

```sh
sudo dnf copr enable coder966/soapui
sudo dnf install soapui
```

## VisualVM
Please make sure you have Java installed.

```sh
sudo dnf copr enable coder966/visualvm
sudo dnf install visualvm
```



## KeyStore Explorer
Please make sure you have Java installed.

```sh
sudo dnf copr enable coder966/keystore-explorer
sudo dnf install keystore-explorer
```
